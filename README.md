# TaskTracker

Sistema de gerenciamento de tarefas desenvolvido em Python 3 para a Fase 2 do Bootcamp II

# Objetivo

O objetivo do projeto é permitir o cadastro e a visualização de tarefas por meio de um menu interativo no terminal.

# Funcionalidades

- Cadastrar novas tarefas
- Validar o preenchimento obrigatório do título
- Validar a prioridade da tarefa
- Registrar descrição e data limite
- Definir automaticamente o status como Pendente
- Visualizar todas as tarefas cadastradas
- Exibir mensagens para opções inválidas e listas vazias

# Tecnologias utilizadas

- Python 3
- Git
- GitHub

# Estrutura do projeto

- `src/main.py`: código-fonte da aplicação
- `docs/planejamento_logico.pdf`: documento de planejamento da Fase 1
- `.gitignore`: arquivos e pastas que não devem ser versionados

# Como executar

1. Instale o Python 3
2. Abra o terminal na pasta principal do projeto
3. Execute:

   `python src/main.py`

No Windows, também é possível utilizar:

   `py src/main.py`

# Observação

As tarefas são armazenadas temporariamente na memória durante a execução do programa. Ao encerrar a aplicação, elas não ficam salvas
